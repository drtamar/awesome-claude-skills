# Security Model

The local proxy runs on your machine with the ability to execute automations in your browser and (optionally) run the Claude Code CLI on your disk. The following defences are **mandatory, not optional** — the proxy refuses to start without them.

## What's enforced

1. **Required HMAC request signing (fail-closed).**
   Every `/api` request must carry an `x-signature` + `x-timestamp` header computed over the canonical string `ts:METHOD:path:body` with HMAC-SHA256. Unsigned, mis-signed, or stale (>30s) requests return 401. The server refuses to start if `SIGNING_SECRET` is missing, default, or shorter than 32 characters.

2. **Origin allowlist.**
   CORS and the WebSocket upgrade both accept only `chrome-extension://` origins. Regular web pages — even on localhost — cannot reach the proxy. For maximum isolation, set `ALLOWED_EXTENSION_IDS` to your exact extension ID (visible on `chrome://extensions`) instead of `*`.

3. **WebSocket signing.**
   Each `stream_chat` message carries its own signature over `ts:WS:sessionId:message`. The upgrade is rejected before the socket opens if the origin fails the allowlist.

4. **Claude Code execution is gated.**
   `/api/claude-code` returns 403 unless `ALLOW_CLAUDE_CODE_EXEC=true` is explicitly set in `.env`. This endpoint runs the Claude Code CLI on your machine with `spawn` — treat enabling it as granting the extension (and anything that compromises it) command execution.

5. **UI output is HTML-escaped.**
   Popup and dashboard escape all model- and page-sourced text before any `innerHTML` write.

6. **Rate limit scoped to `/api`.**
   Health polling from the popup does not consume the request budget.

## What you must do

1. **Paste `SIGNING_SECRET` into the extension Options page** after loading the unpacked extension. Without it, every call fails with a clear error. (The setup script writes a 64-hex-char value to `.env` automatically.)
2. **Keep `ALLOW_CLAUDE_CODE_EXEC=false`** unless you specifically want the "run Claude Code on my machine" feature. If you do turn it on, close the extension when you're not using it.
3. **After loading the extension**, consider replacing `ALLOWED_EXTENSION_IDS=*` with the extension's exact ID.
4. **Treat prompts, scraped page text, and automation step JSON as untrusted input.** The extension never evaluates them outside `chrome.scripting.executeScript`, and the UI escapes them before display — don't bypass either path.

## Known residual risks

- Automations generated by the model execute arbitrary JavaScript in the active tab via `chrome.scripting.executeScript`. You are implicitly trusting the model to produce safe code for the pages you point it at.
- The `/api/automation/:id/run` and `/api/claude-code` endpoints share one secret; if the secret leaks, an attacker on your machine can drive the proxy. Keep `.env` out of git (it is in `.gitignore`).
- No multi-user isolation — this is a single-user local tool.
