# Font Library Reference

All fonts listed here are available via Google Fonts unless noted as "System" or "Variable".
CSS import: `https://fonts.googleapis.com/css2?family=FONT+NAME:wght@400;700&display=swap`
For variable fonts append `:ital,opsz,wght@...` axes as needed.

## Sans-Serif Fonts

### Geometric Sans

**Inter** — The modern workhorse. Extremely legible at all sizes. Variable font (wght 100–900).
- CSS: `family=Inter:wght@100..900`
- Best for: UI, minimalist, corporate, tech
- Personality: neutral, clean, functional
- Pairs with: Playfair Display, Merriweather

**Poppins** — Geometric circles. Friendly and modern.
- CSS: `family=Poppins:wght@300;400;600;700`
- Best for: startups, apps, playful-corporate
- Personality: approachable, modern
- Pairs with: Nunito, Lato

**Raleway** — Elegant thin lines. Beautiful at large sizes.
- CSS: `family=Raleway:wght@100;300;400;700;900`
- Best for: fashion, art, geometric posters
- Personality: sophisticated, light
- Pairs with: Josefin Sans

**DM Sans** — Clean, contemporary. Excellent small sizes.
- CSS: `family=DM+Sans:wght@300;400;500;700`
- Best for: SaaS, minimal, editorial
- Personality: modern, trustworthy

**Josefin Sans** — Art deco geometric. All-caps looks exceptional.
- CSS: `family=Josefin+Sans:wght@300;400;700`
- Best for: Art deco, poster, luxury
- Personality: vintage-modern, elegant

### Humanist Sans

**Source Sans 3** — Adobe's workhorse. Ultra readable.
- CSS: `family=Source+Sans+3:wght@300;400;600;700`
- Best for: long text, reports, corporate
- Personality: readable, neutral

**Nunito** — Rounded terminals. Warm and approachable.
- CSS: `family=Nunito:wght@300;400;700;900`
- Best for: apps, children, friendly brands
- Personality: soft, warm, modern

**Lato** — Humanist. Semi-rounded. Professional.
- CSS: `family=Lato:wght@300;400;700;900`
- Best for: corporate, editorial, long-form
- Personality: professional, friendly

**Open Sans** — Google's flagship humanist. Exceptional readability.
- CSS: `family=Open+Sans:wght@300;400;600;700;800`
- Best for: UI, body text, corporate
- Personality: clean, neutral, readable

### Condensed Sans

**Barlow Condensed** — Athletic condensed. Great impact at large sizes.
- CSS: `family=Barlow+Condensed:wght@400;600;700;800;900`
- Best for: sports, street, impactful headlines
- Personality: strong, urban

**Oswald** — Classic condensed. Versatile and bold.
- CSS: `family=Oswald:wght@300;400;500;600;700`
- Best for: posters, banners, headlines
- Personality: bold, authoritative

**Bebas Neue** — All-caps only. Maximum impact.
- CSS: `family=Bebas+Neue`
- Best for: posters, sports, high-impact display
- Personality: bold, uppercase, cinematic
- Note: Uppercase only — never use for body text

### Grotesque / Neutral

**Space Grotesk** — Tech-forward grotesque. Quirky details.
- CSS: `family=Space+Grotesk:wght@300;400;500;600;700`
- Best for: tech, brutalist, startup
- Personality: technical, contemporary

**Epilogue** — Variable grotesque. Full-range weights.
- CSS: `family=Epilogue:wght@100..900`
- Best for: editorial, brutalist, tech
- Personality: versatile, contemporary

**Syne** — Wide, eccentric. Excellent for display.
- CSS: `family=Syne:wght@400;500;600;700;800`
- Best for: vaporwave, experimental, display
- Personality: bold, expressive, modern

## Font Loading (HTML/SVG)

```html
<!-- Multiple fonts in one request -->
<link href="https://fonts.googleapis.com/css2?family=Playfair+Display:wght@700;900&family=Source+Sans+3:wght@400;600&display=swap" rel="stylesheet">
```

```css
/* In SVG defs */
@import url('https://fonts.googleapis.com/css2?family=Bebas+Neue&display=swap');
```

```python
# Python: download font TTF
import urllib.request
urllib.request.urlretrieve(
    "https://github.com/google/fonts/raw/main/ofl/inter/Inter%5Bslnt%2Cwght%5D.ttf",
    "Inter.ttf"
)
font = ImageFont.truetype("Inter.ttf", 80)
```
